# История работы с AI

Пять промптов, которые реально двигали разработку. Писал человек, выполнял Cursor.

## 1. Собрать внутренний стол заявок, а не учебный CRUD

**Промпт:**  
Собери мини-сервис учёта заявок для небольшой команды. Не делай очередной todo-list: нужна форма (имя, телефон, комментарий, источник), список, статусы «Новая / В работе / Успешно / Отказ», смена статуса, фильтр и сохранение. Backend на ASP.NET, frontend на React, база — мой локальный PostgreSQL. Интерфейс должен выглядеть как рабочий внутренний инструмент, который можно показать за 30 секунд.

**Результат:**  
Появились API, React-страница «Стол заявок» и таблица `leads` в Postgres.

**Что доработал сам:**  
Убрал шаблонный WeatherForecast, переименовал сущности под заявки, руками поправил форму и список, чтобы это не выглядело как дефолтный Vite-экран.

## 2. Один endpoint для внешней CRM — без фейковой «сложной интеграции»

**Промпт:**  
Представь, что к сервису подключат внешнюю CRM. Сделай один API endpoint, через который она сможет создать заявку и получить список. Полноценный OAuth не нужен: покажи, как бы ты организовал такую интеграцию — отдельный контур, общий сервис с UI, простой API-ключ в заголовке, без дублирования бизнес-логики.

**Результат:**  
Ресурс `GET|POST /api/integration/leads` с фильтром `X-Api-Key` и общим `LeadService`.

**Что доработал сам:**  
Развёл UI-контроллер и CRM-контроллер по папкам, проверил 401 без ключа и создание заявки с ключом, поправил тексты ошибок и пример в `.http` файле.

## 3. Подключиться к Postgres на этой машине, не тащить Docker и секреты в Git

**Промпт:**  
Не поднимай Docker. У меня уже стоит PostgreSQL. Найди локальный инстанс, создай базу `testtask`, сохрани пароль только в переменной окружения. В репозитории — строка подключения без пароля, `.gitignore` и `.env.example`. Если что-то пойдёт не так с портами 16/18 версии — разберись сам и напиши, как запускать.

**Результат:**  
База на порту 5432, схема через `EnsureCreated`, пароль читается из `POSTGRES_PASSWORD`.

**Что доработал сам:**  
Проверил, что в Git нет пароля, поправил инструкцию запуска из корня через `--project`, чтобы `dotnet run` не искал csproj в корне.

## 4. Источник — нормальное меню, статусы — читаемые плашки

**Промпт:**  
Поле «Источник» сейчас выглядит как обычный инпут. Сделай аккуратное выпадающее меню с живым списком каналов: сайт, телефон, почта, мессенджеры, реклама, партнёры, CRM. На карточках заявок статусы должны считываться за секунду: те же цвета, но плашка чуть крупнее и с заливкой. Без UI-кита и без фиолетового «AI-дашборда».

**Результат:**  
Кастомный `SourceSelect` и цветные плашки статусов на списке.

**Что доработал сам:**  
Расширил список источников, подкрутил размеры и контраст плашек, убрал лишнюю печать «TestTask» в шапке.

## 5. Доведи репозиторий до вида, который не стыдно сдать

**Промпт:**  
Разложи проект так, чтобы по папкам было понятно, где API, где UI, где интеграция. Коммиты осмысленные, `.gitignore` без bin/obj/node_modules, никаких ключей. README — как запустить, какой стек, что делал AI, что делал я, какие решения и что улучшил бы. Отдельно — 3–5 показательных промптов. Не пиши, что «всё сгенерировал AI»: я рефакторил код и руками правил компоненты.

**Результат:**  
Структура `backend/` + `frontend/`, Git на `main`, README и этот файл.

**Что доработал сам:**  
Перечитал формулировки, убрал канцелярит, явно зафиксировал, что после генерации код рефакторился вручную: сервис заявок, CRM-контур, форма, фильтры и статусы.
